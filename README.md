## Описание
Программный модуль для генерации, очистки, статистического анализа и визуализации числовых данных.

Индивидуальное задание «SimpleAnalysis»:
- Генерация 1000 случайных целых чисел в диапазоне [-10000; 10000]
- Расчет статистических характеристик (min, max, sum, mean, median, std, дубликаты)
- Округление до сотен по математическому правилу
- Визуализация: линейный график, гистограмма, совмещенные сортированные графики
- Формирование DataFrame с сортировкой

## Структура проекта
- `data_generator.py` - генерация данных
- `data_cleaner.py` - очистка от цифрового мусора
- `analyzer.py` - статистический анализ
- `visualizer.py` - визуализация
- `main.py` - главный модуль
- `test_modules.py` - модульное тестирование (13 тестов)
